# NF Ingénierie — site GitHub Pages

Site statique prêt à être publié sur GitHub Pages, sans étape de compilation.

## Fichiers principaux

- `index.html` : page d’accueil
- `contact.html` : page de contact
- `assets/css/style.css` : styles et responsive
- `assets/js/main.js` : menu mobile, animations sobres, année automatique
- `assets/js/contact.js` : préparation d’un email via le logiciel de messagerie du visiteur
- `assets/images/logo-nf-ingenierie.png` : logo fourni
- `robots.txt` et `sitemap.xml` : bases SEO

## Publication

Téléverser le contenu du dossier à la racine du dépôt GitHub Pages. Aucun framework ni gestionnaire de dépendances n’est nécessaire.

## À compléter plus tard

Les réalisations ne sont volontairement pas inventées. Dès que des références vérifiables sont disponibles, ajouter des études de cas avec : photographie, typologie, localisation, mission, lots, enjeux, solutions, année et statut.
